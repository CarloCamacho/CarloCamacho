I build small, weirdly specific tools that make a Linux desktop feel like home.

## What I make

Most of my work is **plugins for [Noctalia](https://noctalia.dev)** — plus the file
manager that runs them.

- 🛰 **[taildrop](https://github.com/CarloCamacho/noctalia-taildrop)** — yeet a file to any
  machine on your tailnet from a file manager's right-click menu.
- 🤖 **[llama-swap](https://github.com/CarloCamacho/noctalia-llama-swap)** — a bar icon, live
  tok/s sparkline, and one-click model load/unload for your local LLM server.
- ☁️ **[onedrive](https://github.com/CarloCamacho/noctalia-onedrive)** — OneDrive sync status
  with live progress, recent files, and pause/resume.
- 🗂 **[hyprfm](https://github.com/CarloCamacho/hyprfm)** — a lightweight Qt6/QML file manager
  for Hyprland.
